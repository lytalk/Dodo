# 嘟嘟

[English](README.md)

嘟嘟（Dodo）让手机按时帮你做事。

在嘟嘟里保存任务：一个时间，加上要执行的步骤。到点后，嘟嘟打开你选的应用，再按步骤操作。跑完可以把任务名和结果发到企业微信群。

## 运行环境

- Android 12（API 31）。`compileSdk 35` 只在编译时使用。
- 实测机型：Redmi K40（`M2012K11AC`，设备名 `alioth`），Android 12，MIUI V13.0.7.0.SKHCNXM，arm64-v8a，已 root。
- 自启动、后台弹出界面、省电设置按这台手机的 MIUI 来写。
- 关闭应用需要 root，通过 `su` 执行 `am force-stop`。其他步骤不需要 root。

## 权限

安装后打开权限页。有任务启用时，通知栏会显示「嘟嘟守护中」，到点的任务才能被拉起来。

1. **无障碍服务。** 嘟嘟用它读取其他应用的文字和控件，并执行点击、输入、返回。在系统的无障碍设置里打开嘟嘟。
2. **精确闹钟。** 到点由系统唤醒嘟嘟。状态栏上的闹钟图标只表示有定时在等待，不用去时钟里设置。
3. **显示在其他应用上层。** 从后台打开别的应用时需要。
4. **Root。** 点「申请 Root」，在 Magisk 或 KernelSU 的弹窗里允许嘟嘟。只有「关闭应用」用到它。
5. **自启动。** 在 MIUI 的自启动列表里打开嘟嘟。关掉之后，开机或进程被清掉以后，到点不会再执行。
6. **后台弹出界面。** 在 MIUI 的权限编辑里打开。打开其他应用时用到的关联启动也在这一页。
7. **省电策略。** 把嘟嘟设为无限制。
8. **最近任务。** 在最近任务里锁定嘟嘟，避免上滑清理时被划掉。不要在手机管家或安全中心里对嘟嘟使用「结束进程」或「强行停止」。那样做之后，定时和无障碍会停，需要再打开一次嘟嘟。

## 任务

在首页新建任务。任务卡片上可以立即运行、复制、进入编辑。复制出来的名字是「原名 副本」，默认关闭。编辑页右上角也可以按当前内容复制一份，同样默认关闭。

启用的任务在保存时向系统登记下一次执行。编辑页会显示下一次是今天还是明天。

### 时间

- **每天。** 选一个钟点。还没到，就从今天开始；已经过了，从明天开始。
- **每周。** 再勾选星期。今天被勾上，并且钟点还没到，就从今天开始。
- **执行一次。** 选日期和钟点。只改钟点、没有自己选过日期时，同样按今天还来不来得及来算。跑完这一次后，任务关闭。
- **每分钟。** 1、5、10、15、30 分钟，从当前时间往后算。每次到点后再按同样的间隔登记。
- **每小时。** 1、2、3、6、12 小时，算法相同。

### 步骤

在「添加步骤」里添加。长按一条步骤可以拖动，旁边的步骤会让出空隙，松手后插入。也可以置顶、上移、下移。

- **打开应用。** 从已安装的应用里选一个。
- **解锁屏幕。** 重放你录下的滑动或多次点击，而且只在锁屏时执行。已经解锁就跳过这一步，继续后面的步骤。录制时，上方的条用来保存，其余位置用来录。要对着锁屏图案录，开始后按电源键锁屏，录制层还在上面。这一步放在任务最前面。
- **关闭应用。** 通过 root 强行停止该应用。没有授权时，到权限页再申请一次。
- **点击文字。** 在整个界面里找这段文字，不在当前画面上时会先滚动再点。
- **点选控件。** 先把目标应用停在要操作的那一页，回到嘟嘟点「开始点选」，再点那个图标或按钮。嘟嘟记下它的 id、文字或位置。
- **手动填写控件 id。** 已经知道完整 id 时直接填，例如 `com.tencent.mm:id/icon`。
- **输入文字。** 写入指定的输入框。目标文字和 id 都留空时，写入当前焦点，或页面上第一个输入框。
- **等待一段时间。** 按毫秒等待，最长 120 秒。
- **等到文字出现。** 等到界面上出现这段文字，超时按秒设置。
- **按返回。** 按一次系统返回。

### 步骤失败之后

步骤列表下面可以设置重试次数和兜底清理。

重试可以不重试，或失败后再从头跑 1 次、2 次、3 次。清理可以不清理、回到桌面、关闭这次任务打开过的应用，或单独指定一步。

某一步失败后，先做清理。还有剩余次数就从头再跑。次数用完后，结果里保留原来的失败原因。清理自己失败时，说明会补在结果后面。

## 企业微信机器人

任务里的「企业微信机器人地址」填群机器人的地址，可以留空。地址以 `http://` 或 `https://` 开头。

执行结束后，嘟嘟把任务名、结果和时间发到群里。消息是企业微信机器人的文本格式：

```json
{
  "msgtype": "text",
  "text": {
    "content": "嘟嘟「任务名」\n结果：成功\n时间：11月6日 21:30"
  }
}
```

发送失败时，企业微信返回的说明会附在任务结果后面。

## 开发

改代码前先看 [开发者手册](docs/开发者手册.md) 和 [开发规范](docs/开发规范.md)。规范里是已经出过的故障和对应修法。用户说明若和代码不一致，以代码和手册为准。

## 编译

需要 JDK 17，并配置 Android SDK：环境变量 `ANDROID_HOME`，或 `local.properties` 里的 `sdk.dir`。

```bash
./gradlew :app:assembleDebug
```
